## 1. 画面一覧

| 画面ID | 画面名 | 主な利用者 | 概要 |
|--------|--------|------------|------|
| SCR-001 | ログイン画面 | 夫・妻 | メール＋パスワードで認証 |
| SCR-002 | 明細一覧画面 | 夫・妻 | 月選択・絞り込み・明細確認 |
| SCR-003 | 明細仕分け画面 | 主に妻 | 未分類や誤分類の修正 |
| SCR-004 | グラフ・集計画面 | 夫・妻 | カテゴリ別・名義人別の可視化 |
| SCR-005 | アップロード画面 | 主に夫 | CSV/PDF明細のアップロード |
| SCR-006 | カテゴリ管理画面 | 夫・妻 | カテゴリの追加・編集・削除 |
| SCR-007 | 分類ルール管理画面 | 夫・妻 | 店名パターン分類ルール管理 |
| SCR-008 | 固定費管理画面 | 夫・妻 | 固定費マスター管理 |
| SCR-009 | 手動支払い登録画面 | 夫・妻 | 現金払いなど明細外支払い登録 |

## 2. 画面遷移（初期想定）

```text
ログイン
  └─ メイン（下部ナビ: 明細 / グラフ）
      ├─ 明細一覧（タブ「明細」）
      │   ├─ 明細仕分け
      │   ├─ アップロード
      │   └─ 設定系（メニュー）
      │       ├─ カテゴリ管理
      │       ├─ 分類ルール管理
      │       ├─ 固定費管理
      │       └─ 手動支払い登録
      └─ グラフ・集計（タブ「グラフ」）
```

## 3. レイアウト方針

- プラットフォーム: Flutter Web（PWA）
- スマホ: ボトムナビゲーション中心
- PC: 将来的にサイドバー対応
- デザイン: シンプル、入力迷いを減らす構成
